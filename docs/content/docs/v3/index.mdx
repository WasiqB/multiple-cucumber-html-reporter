## Overview

Multiple Cucumber HTML Reporter is a reporting tool that parses Cucumber JSON test results and generates a pretty, styled HTML report showing test execution details across multiple browsers/devices.

Refer to the [latest version documentation](/docs/latest) for details on configuration options, as many concepts remain similar.
